Mastering React Reconciliation & Fiber Architecture

calendar_today Published Oct 24, 2023
schedule 12 min read
person By Dev Scholar

The introduction of the Fiber architecture in React 16 wasn't just a performance boost—it was a fundamental rewrite that enabled concurrent features.

1 What is Reconciliation?

Reconciliation is the algorithm React uses to diff one tree with another to determine which parts need to be changed. In the older stack reconciler, this process was recursive and synchronous, which could lead to main-thread blocking during complex updates.

DiffingComponent.tsx 
const diffTrees = (oldTree, newTree) => {
  // Check if root nodes match
  if (oldTree.type !== newTree.type) {
    // Complete re-render needed
    return replaceNode(oldTree, newTree);
  }
  
  // Diff props and children
  updateProps(oldTree, newTree.props);
  diffChildren(oldTree.children, newTree.children);
};

2 The Fiber Transformation

Fiber represents a unit of work. By breaking reconciliation into smaller, incremental units, React can pause, resume, or discard work based on priority. This is the foundation of Concurrent Mode.

  • check_circle Incremental Rendering: Splitting work into chunks.
  • check_circle Task Prioritization: High-priority tasks (input) take precedence.
  • check_circle Pause & Resume: The main thread remains responsive.
